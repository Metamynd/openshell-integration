# Security policy

This integration sits in the path of an agent's outbound actions: the OpenShell supervisor asks MetaMynd to authorize
each one before it reaches the service. We would much rather hear about a weakness from you than from an incident.

## Reporting

**Do not open a public issue for a security report.**

Email **security@metamynd.ai**.

Include what you have: the commit or version, what you did, what happened, and what you expected. A rough report is
more useful to us than a polished one you never send.
